# Local data only

Download the licensed CSV from https://www.kaggle.com/datasets/joniarroba/noshowappointments after verifying source and terms.

Store it locally as data/raw/appointments.csv. Raw files are gitignored. Generated aggregate outputs go into outputs/ and are also gitignored pending ethics/quality review.

Never push patient-level rows, identifiable IDs or unreviewed medical information to this public repository.
